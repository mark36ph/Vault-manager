# Fact Vault Manager

Native C#/.NET Windows desktop software for managing and producing fact-based short-form video projects.

## Development

Build the desktop app:

```powershell
dotnet build hybrid\FactVaultManager.Desktop\FactVaultManager.Desktop.csproj
```

Run the native test suite:

```powershell
dotnet test hybrid\FactVaultManager.Desktop.Tests\FactVaultManager.Desktop.Tests.csproj
```
